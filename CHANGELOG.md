# Changelog

## 0.1.1 — 2026-10-19

- README и skill переведены на универсальную подачу: инструмент для любого проекта,
  недвижимость — один из контекстов, а не область применения;
- убраны оговорки, сужавшие применение и дублировавшие юридический раздел;
- примеры CLI/API/Django сделаны нейтральными;
- в документации сохранены правовые детали и ограничения метода.

## 0.1.0 — 2026-10-19

Первая версия.

- детектор латиницы с корректными позициями по исходной строке;
- обнаружение смешанных алфавитов (гомоглифов) с Unicode-кодами;
- маскирование HTML/JSX/Markdown: теги, атрибуты, код, URL, e-mail;
- риск-модель: `LIKELY_VIOLATION`, `NEEDS_REVIEW`, `NO_ISSUE_FOUND`, `NOT_APPLICABLE`;
- правовой контекст: реклама, публичная информация, внутренний интерфейс,
  реклама ДДУ, дата ввода, товарный знак;
- выборочные правила заимствований и UI-меток с основанием и уверенностью;
- CLI `fz168`, Python API, валидатор Django;
- skill для LLM-агентов и правила Cursor;
- документация: правовая основа, данные и лицензии, схема правил, источники.
