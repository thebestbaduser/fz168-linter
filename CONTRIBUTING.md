# Как участвовать

## Правила

1. Одно правило — один признак. Не смешивайте «слова нет в словаре» и «слово
   запрещено».
2. У каждого правила обязательны `legal_basis` и `source`. Блог, пересказ или
   «в интернете писали» источником не считаются.
3. Если слово может быть в актуальной редакции нормативного словаря —
   `confidence: low` и оговорка в `reason`.
   Для утверждения о словарной статье нужны точное значение, страница и дата
   проверки. Ссылка на словарь целиком не доказывает отсутствие слова.
4. Не добавляйте утверждения о штрафах: санкции живут в `docs/LEGAL.md`,
   а не в правилах.
5. Не добавляйте массовые извлечения из словарей: см. `docs/DATA.md`.

## Тесты

```bash
python -m unittest discover -s tests -v
```

Новое поведение — новый тест. Регрессии по статусам и позициям обязательны.

## Pull request

- опишите норму или источник;
- приложите пример «до/после»;
- проверьте, что тесты зелёные;
- если меняется правовая часть — обновите `docs/LEGAL.md` и `docs/SOURCES.md`.
