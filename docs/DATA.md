# Нормативные словари и данные

Дополнения: № 757-р от 06.04.2026 (+5) и № 1406-р от 08.06.2026 (+2).

## Как это используется

- Для заимствований практически значим **Словарь иностранных слов**. Остальные
  словари выполняют иные функции; складывать их в один whitelist нельзя.
- Отсутствие слова в словаре **не является запретом**: нужна оценка сферы,
  функции текста и наличия русского содержания. Поэтому статус — `NEEDS_REVIEW`,
  а не `LIKELY_VIOLATION`.
- Встроенные списки — выборочные, с указанием источника и `confidence`.
  Это не полный корпус.

## Лицензии

- Код — MIT.
- Тексты словарей — объекты авторского права и (для баз данных) предмет
  смежного права изготовителя базы данных (ст. 1259, 1260, 1334 ГК РФ).
  Нормативный статус словаря не делает его содержимое свободным от прав.
- Поэтому в репозитории **нет** массового извлечения словарного корпуса:
  только небольшие проверяемые списки слов с указанием источника.
- Если нужен полный объём — получите разрешение правообладателей либо
  используйте собственные данные, не распространяя их под MIT.

## Свои данные

- Слова-исключения: `extra_whitelist` в API.
- Бренды: `extra_trademarks` в API или `--trademark-word` в CLI.
- Новые правила: `src/fz168_linter/data/rules_re.json` (см. [RULES.md](RULES.md)).
